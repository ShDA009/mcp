# Установка outlook-mcp (для сотрудников)

Скрипты настраивают MCP-сервер `outlook-mcp` (чтение календаря и почты
Exchange через EWS) для Cline в VS Code. Запуск сервера идёт через `uv`/`uvx` —
**Docker не нужен**, прав администратора/sudo тоже.

Что делает скрипт:
1. Находит `uv` (или предлагает установить — только с вашего согласия).
2. Спрашивает креды Exchange (URL, логин, email, пароль — ввод пароля скрыт).
3. Сохраняет их локально в защищённый файл `.env` (в открытую сеть ничего не уходит).
4. Прописывает сервер в конфиг Cline.
5. Проверяет, что пакет скачивается и запускается.

Повторный запуск безопасен: существующий `uv` переиспользуется, секция в
конфиге Cline обновляется на месте (не дублируется), текущие креды можно
оставить без изменений.

Понадобится: доступ в интернет (к `github.com` и `astral.sh`) и **корпоративный
VPN** для реального доступа к Exchange.

---

## Windows

1. Скачайте файл **`setup.ps1`**.
2. Правый клик по файлу → **«Выполнить с помощью PowerShell»**.
3. Если запуск блокируется политикой выполнения (ExecutionPolicy) — откройте
   PowerShell и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
4. Ответьте на вопросы:
   - ставить ли `uv` (если не найден) — `y`;
   - при повторной установке — менять ли креды (`y`/`n`);
   - введите EWS URL, логин, email и пароль.
5. Полностью перезапустите VS Code.

---

## macOS (только Apple Silicon, arm64)

> Intel/Rosetta не поддерживается.

1. Скачайте файл **`setup.sh`**.
2. Откройте Терминал в папке со скриптом и запустите:
   ```bash
   bash setup.sh
   ```
   Запускайте именно так — **не двойным кликом** (иначе сработает Gatekeeper/
   карантин).
3. Ответьте на вопросы (установка `uv`, смена кредов, параметры EWS).
4. Полностью перезапустите VS Code.
5. Если EWS недоступен — проверьте, что подключён **корпоративный VPN**.

---

## Linux

1. Скачайте файл **`setup.sh`**.
2. Запустите:
   ```bash
   bash setup.sh
   ```
3. Ответьте на вопросы (установка `uv`, смена кредов, параметры EWS).
4. Полностью перезапустите VS Code.
5. Если EWS недоступен — проверьте доступ в корпоративную сеть / VPN.

Нужны стандартные утилиты `curl`, `bash`, `python3` (обычно уже есть).

---

## Где что лежит

| | Windows | macOS / Linux |
|---|---|---|
| Креды (`.env`) | `%USERPROFILE%\.outlook-mcp\.env` | `~/.config/outlook-mcp/.env` |
| Конфиг Cline | `%APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json` | `~/Library/Application Support/Code/...` (macOS) / `~/.config/Code/...` (Linux) |

## Если что-то пошло не так

- **`uv`/`uvx` не найден после установки** — перезапустите терминал (PowerShell)
  и запустите скрипт ещё раз.
- **Ошибка скачивания пакета** — проверьте доступ к `github.com` (интернет,
  прокси).
- **Cline не видит сервер** — полностью закройте и откройте VS Code; проверьте,
  что сервер `outlook-mcp` включён в списке MCP Cline.
- **EWS недоступен / ошибки подключения** — подключите корпоративный VPN.
- Пароль нигде не выводится в лог и не пишется в открытом виде в консоль. Если
  нужно сменить креды — просто запустите скрипт снова и ответьте `y` на вопрос
  о смене.

При других проблемах обращайтесь к администратору outlook-mcp.
