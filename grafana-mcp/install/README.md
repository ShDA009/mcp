# Установка grafana-mcp (для сотрудников)

Скрипты настраивают MCP-сервер `grafana` (дашборды, datasources, запросы к
данным, алерты; сторонний код
[grafana/mcp-grafana](https://github.com/grafana/mcp-grafana)) для
Cline в VS Code. Запуск идёт через `uv`/`uvx` — **Docker не нужен**, прав
администратора/sudo тоже.

Что делает скрипт:
1. Находит `uv` (или предлагает установить — только с вашего согласия).
2. Спрашивает адрес Grafana (`GRAFANA_URL`) и токен service account
   (`GRAFANA_SERVICE_ACCOUNT_TOKEN`, ввод скрыт).
3. Сохраняет всё локально в защищённый файл `.env` (в открытую сеть ничего не уходит).
4. Генерирует **лаунчер** рядом с `.env` и прописывает его в конфиг Cline —
   **без токена и без версии пакета**: лаунчер сам читает `.env` и
   подтягивает актуальную версию из репозитория при каждом запуске сервера.
   Сервер запускается с флагом `--tls-skip-verify` (корпоративные
   самоподписанные сертификаты).
5. Проверяет, что пакет скачивается и запускается (`--help`).

Повторный запуск безопасен: существующий `uv` переиспользуется, секция в
конфиге Cline обновляется на месте (не дублируется), текущие настройки можно
оставить без изменений.

Понадобится: доступ в интернет (к `github.com`, `pypi.org` и `astral.sh`),
**корпоративный VPN** для реального доступа к Grafana и токен service account
(выдаёт администратор Grafana).

**Обновление версии не требует переустановки** — если версия пакета поднята
в `mcp-versions.txt` репозитория, лаунчер подхватит её сам при следующем запуске
сервера (см. корневой [README.md](../../README.md)).

## Windows

1. Скачайте файл **`setup.ps1`**.
2. Правый клик по файлу → **«Выполнить с помощью PowerShell»**.
3. Если запуск блокируется политикой выполнения (ExecutionPolicy) — откройте
   PowerShell и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
4. Ответьте на вопросы:
   - ставить ли `uv` (если не найден) — `y`;
   - при повторной установке — менять ли настройки (`y`/`n`);
   - введите `GRAFANA_URL` и токен service account.
5. Полностью перезапустите VS Code.

---

## macOS (только Apple Silicon, arm64)

> Intel/Rosetta не поддерживается.

1. Скачайте файл **`setup.sh`**.
2. Откройте Терминал в папке со скриптом и запустите:
   ```bash
   bash setup.sh
   ```
   Запускайте именно так — **не двойным кликом** (иначе сработает Gatekeeper/
   карантин).
3. Ответьте на вопросы (установка `uv`, адрес Grafana, токен).
4. Полностью перезапустите VS Code.
5. Если Grafana недоступна — проверьте, что подключён **корпоративный VPN**.

---

## Linux

1. Скачайте файл **`setup.sh`**.
2. Запустите:
   ```bash
   bash setup.sh
   ```
3. Ответьте на вопросы (установка `uv`, адрес Grafana, токен).
4. Полностью перезапустите VS Code.
5. Если Grafana недоступна — проверьте доступ в корпоративную сеть / VPN.

Нужны стандартные утилиты `curl`, `bash`, `python3` (обычно уже есть).

## Где что лежит

| | Windows | macOS / Linux |
|---|---|---|
| Настройки (`.env`) | `%USERPROFILE%\.grafana-mcp\.env` | `~/.config/grafana-mcp/.env` |
| Лаунчер | `%USERPROFILE%\.grafana-mcp\launch.cmd` (+ `launch.ps1`) | `~/.config/grafana-mcp/launch.sh` |
| Конфиг Cline | `%APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json` | `~/Library/Application Support/Code/...` (macOS) / `~/.config/Code/...` (Linux) |

## Если что-то пошло не так

- **`uv`/`uvx` не найден после установки** — перезапустите терминал (PowerShell)
  и запустите скрипт ещё раз.
- **Ошибка скачивания пакета** — проверьте доступ к `pypi.org` (интернет, прокси).
- **Cline не видит сервер** — полностью закройте и откройте VS Code; проверьте,
  что сервер `grafana` включён в списке MCP Cline.
- **Grafana недоступна / ошибки подключения** — подключите корпоративный VPN,
  проверьте `GRAFANA_URL`.
- **Ошибка 401/403 от Grafana** — токен неверный, просрочен или у service account
  не хватает прав; запросите новый токен у администратора Grafana.
- Токен нигде не выводится в лог и не пишется в открытом виде в консоль. Если
  нужно его сменить — просто запустите скрипт снова и ответьте `y` на вопрос об
  изменении.

При других проблемах обращайтесь к администратору grafana-mcp.
