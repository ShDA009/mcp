# Установка mcp-atlassian (для сотрудников)

Скрипты настраивают MCP-сервер `mcp-atlassian` (Jira + Confluence, сторонний
код [sooperset/mcp-atlassian](https://github.com/sooperset/mcp-atlassian)) для
Cline в VS Code. Запуск идёт через `uv`/`uvx` — **Docker не нужен**, прав
администратора/sudo тоже.

Что делает скрипт:
1. Находит `uv` (или предлагает установить — только с вашего согласия).
2. Спрашивает креды Jira и Confluence (URL + Personal Access Token каждого,
   ввод токенов скрыт).
3. Сохраняет их локально в защищённый файл `.env` (в открытую сеть ничего не уходит).
4. Генерирует **лаунчер** рядом с `.env` и прописывает его в конфиг Cline —
   **без кредов и без версии пакета**: лаунчер сам читает `.env` и подтягивает
   актуальную версию из репозитория при каждом запуске сервера.
5. Проверяет, что пакет скачивается и запускается (`--help`).

Повторный запуск безопасен: существующий `uv` переиспользуется, секция в
конфиге Cline обновляется на месте (не дублируется), текущие креды можно
оставить без изменений.

Понадобится: доступ в интернет (к `github.com`, `pypi.org` и `astral.sh`) и
**корпоративный VPN** для реального доступа к Jira/Confluence.

**Обновление версии не требует переустановки** — если версия пакета поднята
в `mcp-versions.txt` репозитория, лаунчер подхватит её сам при следующем запуске
сервера (см. корневой [README.md](../README.md)).

## Windows

1. Скачайте файл **`setup.ps1`**.
2. Правый клик по файлу → **«Выполнить с помощью PowerShell»**.
3. Если запуск блокируется политикой выполнения (ExecutionPolicy) — откройте
   PowerShell и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
4. Ответьте на вопросы:
   - ставить ли `uv` (если не найден) — `y`;
   - при повторной установке — менять ли креды (`y`/`n`);
   - введите Confluence URL/токен и Jira URL/токен.
5. Полностью перезапустите VS Code.

---

## macOS (только Apple Silicon, arm64)

> Intel/Rosetta не поддерживается.

1. Скачайте файл **`setup.sh`**.
2. Откройте Терминал в папке со скриптом и запустите:
   ```bash
   bash setup.sh
   ```
   Запускайте именно так — **не двойным кликом** (иначе сработает Gatekeeper/
   карантин).
3. Ответьте на вопросы (установка `uv`, смена кредов, параметры Jira/Confluence).
4. Полностью перезапустите VS Code.
5. Если Jira/Confluence недоступны — проверьте, что подключён **корпоративный VPN**.

---

## Linux

1. Скачайте файл **`setup.sh`**.
2. Запустите:
   ```bash
   bash setup.sh
   ```
3. Ответьте на вопросы (установка `uv`, смена кредов, параметры Jira/Confluence).
4. Полностью перезапустите VS Code.
5. Если Jira/Confluence недоступны — проверьте доступ в корпоративную сеть / VPN.

Нужны стандартные утилиты `curl`, `bash`, `python3` (обычно уже есть).

## Где что лежит

| | Windows | macOS / Linux |
|---|---|---|
| Креды (`.env`) | `%USERPROFILE%\.mcp-atlassian\.env` | `~/.config/mcp-atlassian/.env` |
| Лаунчер | `%USERPROFILE%\.mcp-atlassian\launch.cmd` (+ `launch.ps1`) | `~/.config/mcp-atlassian/launch.sh` |
| Конфиг Cline | `%APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json` | `~/Library/Application Support/Code/...` (macOS) / `~/.config/Code/...` (Linux) |

## Если что-то пошло не так

- **`uv`/`uvx` не найден после установки** — перезапустите терминал (PowerShell)
  и запустите скрипт ещё раз.
- **Ошибка скачивания пакета** — проверьте доступ к `pypi.org` (интернет, прокси).
- **Cline не видит сервер** — полностью закройте и откройте VS Code; проверьте,
  что сервер `mcp-atlassian` включён в списке MCP Cline.
- **Jira/Confluence недоступны / ошибки подключения** — подключите корпоративный VPN.
- Токены нигде не выводятся в лог и не пишутся в открытом виде в консоль. Если
  нужно сменить креды — просто запустите скрипт снова и ответьте `y` на вопрос
  о смене.

При других проблемах обращайтесь к администратору mcp-atlassian.
