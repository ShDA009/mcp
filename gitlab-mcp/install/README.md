# Установка gitlab-mcp (для сотрудников)

Скрипты настраивают MCP-сервер `gitlab-mcp` (сторонний код
[zereight/gitlab-mcp](https://github.com/zereight/gitlab-mcp)) для Cline в
VS Code. Запуск идёт через `npx` — **Docker не нужен**, прав
администратора/sudo тоже.

**Единственное отличие от остальных серверов в репозитории:** этот сервер
написан на Node, а не Python — понадобится установленный **Node.js >= 18**
(его нужно поставить самостоятельно, `uv` его не ставит).

Что делает скрипт:
1. Проверяет наличие `node`/`npx` в PATH (если нет — просит установить Node.js
   вручную и завершается).
2. Спрашивает креды GitLab (API URL и Personal Access Token, ввод токена скрыт).
3. Сохраняет их локально в защищённый файл `.env` (в открытую сеть ничего не уходит).
4. Генерирует **лаунчер** рядом с `.env` и прописывает его в конфиг Cline —
   **без кредов и без версии пакета**: лаунчер сам читает `.env` (сервер не
   умеет `--env-file`, поэтому переменные экспортируются перед запуском) и
   подтягивает актуальную версию из репозитория при каждом запуске.
5. Проверяет, что пакет скачивается и стартует (лог должен содержать
   "Configuration validation passed" — у этого сервера нет `--help`).

Повторный запуск безопасен: секция в конфиге Cline обновляется на месте (не
дублируется), текущие креды можно оставить без изменений.

Понадобится: доступ в интернет (к `github.com` и `registry.npmjs.org`) и
**корпоративный VPN** для реального доступа к GitLab.

**Обновление версии не требует переустановки** — если версия пакета поднята
в `mcp-versions.txt` репозитория, лаунчер подхватит её сам при следующем запуске
сервера (см. корневой [README.md](../README.md)).

## Windows

1. Убедитесь, что установлен [Node.js](https://nodejs.org) (версия >= 18).
2. Скачайте файл **`setup.ps1`**.
3. Правый клик по файлу → **«Выполнить с помощью PowerShell»**.
4. Если запуск блокируется политикой выполнения (ExecutionPolicy) — откройте
   PowerShell и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
5. Ответьте на вопросы (при повторной установке — менять ли креды; введите
   GitLab API URL и Personal Access Token).
6. Полностью перезапустите VS Code.

---

## macOS (только Apple Silicon, arm64)

> Intel/Rosetta не поддерживается.

1. Убедитесь, что установлен Node.js >= 18 (`brew install node` или с
   [nodejs.org](https://nodejs.org)).
2. Скачайте файл **`setup.sh`**.
3. Откройте Терминал в папке со скриптом и запустите:
   ```bash
   bash setup.sh
   ```
   Запускайте именно так — **не двойным кликом** (иначе сработает Gatekeeper/
   карантин).
4. Ответьте на вопросы (смена кредов, параметры GitLab).
5. Полностью перезапустите VS Code.
6. Если GitLab недоступен — проверьте, что подключён **корпоративный VPN**.

---

## Linux

1. Убедитесь, что установлен Node.js >= 18.
2. Скачайте файл **`setup.sh`**.
3. Запустите:
   ```bash
   bash setup.sh
   ```
4. Ответьте на вопросы (смена кредов, параметры GitLab).
5. Полностью перезапустите VS Code.
6. Если GitLab недоступен — проверьте доступ в корпоративную сеть / VPN.

Нужны стандартные утилиты `curl`, `bash`, `python3` (обычно уже есть).

## Где что лежит

| | Windows | macOS / Linux |
|---|---|---|
| Креды (`.env`) | `%USERPROFILE%\.gitlab-mcp\.env` | `~/.config/gitlab-mcp/.env` |
| Лаунчер | `%USERPROFILE%\.gitlab-mcp\launch.cmd` (+ `launch.ps1`) | `~/.config/gitlab-mcp/launch.sh` |
| Конфиг Cline | `%APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json` | `~/Library/Application Support/Code/...` (macOS) / `~/.config/Code/...` (Linux) |

## Если что-то пошло не так

- **Скрипт требует Node.js** — установите с [nodejs.org](https://nodejs.org)
  (версия >= 18) и запустите скрипт снова.
- **Первый запуск медленный** — `npx` качает пакет с нуля при первом старте
  (до ~20 секунд); повторные запуски быстрые за счёт кеша npm.
- **Ошибка скачивания пакета** — проверьте доступ к `registry.npmjs.org`
  (интернет, прокси).
- **Cline не видит сервер** — полностью закройте и откройте VS Code; проверьте,
  что сервер `gitlab-mcp` включён в списке MCP Cline.
- **GitLab недоступен / ошибки подключения** — подключите корпоративный VPN.
- Токен нигде не выводится в лог и не пишется в открытом виде в консоль. Если
  нужно сменить креды — просто запустите скрипт снова и ответьте `y` на вопрос
  о смене.

При других проблемах обращайтесь к администратору gitlab-mcp.
